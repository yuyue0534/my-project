前端热力图 Demo

单文件、零依赖。包含二维工时矩阵、GitHub 风格年度日历、Canvas 点击热力图、业务指标热力表。把鼠标移到格子或热区上查看详细信息。
4 种 Heatmap

1. 工时矩阵热力图

最适合后台系统：人员 × 星期，数值直接映射为颜色深浅，并保留原始数字。
低 高

2. 年度日历热力图

GitHub Contributions 风格，适合每日提交量、访问量、工时、Ticket、考勤异常次数等。
少 多

3. 页面点击热力图（Canvas）

常用于埋点和用户行为分析。下面模拟一个后台页面，热区越亮表示点击越集中；你也可以直接点击画布继续追加热区。
提示：点击画布任意位置，可以模拟新的用户点击；点击“清空点击”可重置。

4. 业务指标热力表

不是所有热力图都需要图表库。企业后台经常直接给表格单元格着色，信息密度高、易读、易与详情钻取结合。
正常 注意 异常
